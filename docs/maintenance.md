## 每周看报

1. 打开 `reports/` 中当天的 `weekly-日期.md`，先看顶部是否“采集覆盖不完整”。
2. 看文末来源状态。正常且 0 条只代表当前列表、日期和关键词没有筛到条目。
3. 若仍缺来源，在 Actions → Weekly Geomatics News → Run workflow 创建新运行。不要反复重跑失效来源。
4. 挑 1～2 条科研线索核对原论文与公开数据；记录“值得读/不相关/漏收”及原因。

## 本机 GitHub 连接异常

2026-10-19 发现 Windows hosts 的 Steam++ 区段将 `github.com` 和 `api.github.com` 指向 `127.0.0.1`，而本机 443 端口没有服务，导致 Git 连接被拒绝。短期可开启原加速软件对应的 GitHub 服务；长期建议在该软件界面关闭 GitHub 加速并恢复其 hosts 条目，或修复其本地服务。

本次没有修改你的 hosts 或其他 Steam 配置。提交使用仅本次进程生效的地址解析，仍保留原域名 TLS 证书校验。若本地再次不能同步，优先检查加速软件状态，不要关闭证书校验。
